# Blog de Artigos com Next.js

Projeto desenvolvido com Next.js utilizando App Router, rotas dinâmicas, Server Components, SEO dinâmico e carregamento de dados por JSON local.

## Funcionalidades

- Página inicial com listagem de artigos
- Rotas dinâmicas para cada artigo
- SEO dinâmico com generateMetadata
- Server Components com async/await
- Geração estática com generateStaticParams
- Layout responsivo

## Tecnologias

- Next.js
- React
- TypeScript
- CSS
- App Router

## Como rodar

```bash
npm install
npm run dev
